# Dokumentation "Hilfmal"


## Administration mit Hilfmal Account auf Chischte

Auf der Chischte, gibt es einen speziellen Account für "Hilfmal", er heisst "Hilfmal".
Dieser Account besitzt Ownership der Kontaktliste und des Kalenders.

Sein Passwort wird unter den Admins von Hilfmal geteilt.
Neue Admins erhalten das Passwort um es ihn ihrem Passwort Programm zu speichern.
Verlässt jemand die Funktion als Admin wird idealerweise das Passwort gewechselt und
das neue Passwort unter den verbleibenden Admins geteilt.


## Administration der Liste der Mitwirkenden

Im Account "Hilfmal" wird ein Adressbuch "Mitwirkende" gepflegt.
In diesem Adressbuch wird für alle Mitwirkende ein Eintrag gepflegt. 
Jeder Eintrag enthält Name, E-Mail-Adresse und die Handy/Telefon Nummer.
Meist kann ein Eintrag aus dem Adressbuch "Konten" kopiert werden. Dazu wird der Kontakteintrag kopiert und kann dann dem Adressebuch "Mitwirkende" angefüht werden.
